## Stack
- Next.js 16.2.6 (Turbopack) + TypeScript + React 19
- Tailwind CSS v4 — config lives in `app/globals.css` via `@theme` block, **no `tailwind.config.js`**
- Framer Motion v12
- `@react-three/fiber` v9 + `@react-three/drei` v10 + Three.js v0.184
- MDX via `@next/mdx` + `gray-matter` + `reading-time`
- Google Fonts: Space Grotesk, Inter, Space Mono (via `next/font`)

## Key architectural rules
- `next/dynamic` with `ssr: false` must live in a `"use client"` wrapper component (e.g. `StarfieldWrapper.tsx`) — never directly in `layout.tsx` (Server Components don't allow it)
- Tailwind v4 uses `@utility` to define custom utilities (`.glass`, `.glow-*`) — no `@layer utilities`
- Three.js packages are in `transpilePackages` in `next.config.ts` (they ship ESM)
- Blog uses static generation: `generateStaticParams` + `dynamicParams = false`

## Blog system

### Content location
All articles: `content/blog/[slug].mdx`

### MDX frontmatter (required fields)
```mdx
---
title: "Article Title"
description: "One sentence description for SEO."
keywords: ["keyword one", "keyword two"]
date: "2026-06-08"
category: THEORY
excerpt: "Short teaser shown on cards."
---
```

Categories: `ASTROBIOLOGY` | `CONSCIOUSNESS` | `PHARMACOLOGY` | `THEORY`

### MDX components available in articles
Defined in `mdx-components.tsx`, imported from `components/blog/BlogGraphic.tsx`:
- `<GlowCard title="" body="" color="violet|teal|amber" />` — glowing definition card
- `<PullQuote>text</PullQuote>` — styled blockquote callout
- `<DataPoint label="" value="" />` — stat highlight
- `<StatGrid>` — grid wrapper for DataPoints
- `<ComparisonTable>` — side-by-side comparison
- `<TimelineGraphic>` — chronological timeline
- `<ConceptDiagram>` — concept visualization

### Blog utilities (lib/blog.ts)
- `getAllPosts()` — returns all posts sorted by date desc
- `getPostBySlug(slug)` — returns single post meta

### Sitemap
Auto-generated via `app/sitemap.ts` from `getAllPosts()` — no manual sitemap file needed. Adding an MDX file is sufficient.

### OG images
Dynamic: `https://www.technospermia.com/og?title=ENCODED_TITLE&category=CATEGORY` (generated by `app/og/`)

## Adding a new blog post — do exactly these things:
1. Create `content/blog/[slug].mdx` with full frontmatter + article body
2. That's it — sitemap and blog listing are auto-generated
